### Bug fixes

- A search for the documents similar to one, such as `like:[P412]`, now answers only a user who may see that document: one who can open a file of it, as a result needs one, and, when Paperless Sync lets them see only the documents with some tags, with one of those tags. Anyone else finds nothing, as for a document that Paperless doesn't have, because the order of the similar documents told something about a document that they may not see. The search asks Paperless for that document with one more short request first.
