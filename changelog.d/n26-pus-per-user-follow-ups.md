### Bug fixes

- **The search finds each user's own documents with Paperless Sync's Each user, those they own or may view in Paperless too.** Paperless Sync gives the owner of each document a copy in that mode as well, and the search now counts it by the same rules as with Each user, those they own in Paperless. Only the copies for the users who may only view a document still don't count, and the warning in the settings, `occ` and the overview now says just that, as decision 0014 records.
- **`occ paperless_unified_search:check` counts the files in each user's own folders.** When Paperless Sync gives each user the documents that they own, the coverage now counts a file of the user of each document's owner, as the search does, instead of the archive account alone, and the check fails when not one document has a file in either place.
- **The files of the owners count at once after the account may view users.** Once you give the account of the API token View for Users, saving the settings again, with the same token, or running `occ paperless_unified_search:check` lets the search read the users of Paperless right away, instead of after ten minutes.
- **A question without an answer no longer asks for View for UI Settings.** When Paperless doesn't answer in time what the account of the API token may do, `occ paperless_unified_search:check` says to run it again, and the overview keeps the warnings of the last test. When Paperless refuses to say, the check still asks for View for UI Settings, and the overview forgets the warnings of an earlier test, such as one about a Superuser that the account no longer is.
