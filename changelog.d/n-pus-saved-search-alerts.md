### Features

- **Notifications about new documents:** nobody had to tell you when a letter of the tax office arrived in Paperless, you had to search again and again. Now, under **Personal settings → Paperless**, **Notify me about new documents** lets each user save up to 10 searches in the syntax of Paperless, such as `correspondent:"tax office"` or `tag:unpaid`, or ask for every new document that they can open. A background job looks every five minutes, and Nextcloud sends each user one notification with links to the files, on the web and to the apps for phones, as soon as the file has arrived and only when the user can open it. Paperless gets one short request per run, and one more per distinct saved search only when a new document has its file. Administrators decide with **Let users ask for notifications about new documents**, or `--new-document-alerts` of `occ paperless_unified_search:setup`; until they do, it is on only where Nextcloud has a memory cache.
