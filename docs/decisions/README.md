# Decisions

The decisions that shape this project, each with its reasons, so that a later change can see why things are as they are. A decision that changes an earlier one gets a new record, and the earlier one says which record replaces it.

Copy [the template](0000-template.md) to the next free number, replace the description at its top with the decision and its reason in one sentence, which search engines and shared links show, and describe the decision in the pull request that makes it.

| [0002](0002-trust-the-archive-account.md) | Trust the owner of a file, not its name | accepted |
| [0003](0003-bind-the-token-to-its-server.md) | Send the stored token only to the server it was saved for | accepted |
| [0004](0004-local-network-opt-in.md) | Allow the local network for this Paperless alone, by a switch of the settings | accepted |
| [0005](0005-name-the-cause-of-a-failed-connection-test.md) | Name the cause of a failed test of the connection, in the language of the administrator | accepted |
